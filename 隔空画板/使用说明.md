# 隔空画板

## 启动

1. 双击 `启动画板.command`。
2. 浏览器打开页面后，点击“启动摄像头”。
3. 允许浏览器使用摄像头。
4. 如需真正全屏，可按浏览器的全屏快捷键。

> 建议使用最新版 Chrome 或 Edge。摄像头需要通过本地服务器访问，直接双击 HTML 文件通常会被浏览器限制。

## 手势

| 操作 | 手势 |
|---|---|
| 写字画画 | 右手只伸食指，识别后立即开始绘制；启笔后会持续锁定当前笔画 |
| 停笔/换位置 | 右手拇指和食指捏合约 0.18 秒；移动到下一笔起点后松开，再只伸食指 |
| 擦除 | 伸出左手食指并移动，避免同时完全张开手掌 |
| 撤回上一笔 | 左手食指与中指组成 V 手势并保持约 0.4 秒 |
| 清空画布 | 左手张开至少三根手指约 0.28 秒，看到“清屏已准备”后握拳约 0.28 秒 |
| 选择颜色 | 左手拇指与食指捏紧，将捏合点移动到色块附近并停留 2 秒；其他手指姿势不受限制 |
| 调整粗细 | 拖动底部滑块，范围为 1–30 px |
| 背景音乐 | 点击右上角“音乐：开/关”切换 |
| 保存作品 | 点击右上角“保存作品”，导出不含界面控件的摄像头与绘画合成图 |

## 绘画工具

- `普通笔`：使用当前颜色和粗细绘制平滑线条。
- `发光笔`：在线条周围增加同色柔光效果。
- `印章`：选择星星、爱心、花朵或笑脸，然后用右手拇指与食指捏合放置。
- 印章大小会随底部粗细滑块变化，印章颜色使用当前选中的颜色。
- 撤回手势与 `Command/Ctrl + Z` 均可撤回刚放置的印章。

## 备用操作

- 鼠标或触控拖动：绘画。
- 按住 `Shift` 再拖动：擦除。
- 按 `C`：清空画布。
- 按 `Command/Ctrl + Z`：撤回上一笔。
- 直接点击左侧色块：立即选色。

## 使用建议

- 光线充足、背景简洁时，手势识别更稳定。
- 双手尽量完整出现在画面里，手掌距离摄像头约 50–100 厘米。
- 取色时不用把手伸到屏幕边缘；进入左侧色板附近后，会出现“保持捏合”提示和连接线。
- 页面会请求摄像头可提供的最高分辨率与连续自动对焦；实际清晰度由摄像头和浏览器决定。
- 启动后会播放轻快但舒缓的合成纯音乐，可用右上角按钮随时关闭。
- 食指轨迹采用增强型速度自适应滤波：慢速书写时强力抑制微小漂移，快速移动时自动降低延迟。
- 右手笔尖锁定后可容忍约 0.7 秒的短暂识别丢失，重新识别时会自动平滑连接轨迹。
- 右手拇指与食指捏合、握拳、张开手掌、清空画布或将右手移出画面后，当前笔画结束。
- 画笔坐标会自动补偿全屏摄像头画面的裁切和镜像，圆形笔尖指示器直接贴合右手食指尖。
