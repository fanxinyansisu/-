# 手机网页部署说明

## 为什么需要部署

手机浏览器通常只允许 `HTTPS` 网页调用摄像头。直接把 HTML 文件发到手机，或通过普通局域网 HTTP 地址打开，摄像头可能会被拦截。

## 最简单的方式

可以把整个“隔空画板”目录或提供的网页部署压缩包上传到任意静态网站托管服务，例如：

- Netlify Drop
- Vercel
- GitHub Pages
- Cloudflare Pages

上传完成后，使用服务生成的 `https://` 地址在手机浏览器中打开。

## 使用 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `air-canvas`。
2. 进入仓库，选择 `Add file` → `Upload files`。
3. 上传部署包解压后的全部内容，确保 `index.html` 和 `.nojekyll` 位于仓库根目录。
4. 提交文件后进入 `Settings` → `Pages`。
5. 在 `Build and deployment` 中选择 `Deploy from a branch`。
6. 分支选择 `main`，目录选择 `/(root)`，然后保存。
7. 等待 GitHub 完成部署，访问 `https://你的用户名.github.io/air-canvas/`。

## 手机上使用

1. 建议使用最新版 Safari、Chrome 或 Edge。
2. 打开网站后点击“启动摄像头”。
3. 允许网站访问摄像头。
4. 将手机横屏放置，确保手掌完整出现在前置摄像头画面中。
5. iPhone 可通过 Safari 的“添加到主屏幕”获得更接近全屏应用的体验。

## 上传要求

- 网站入口是 `index.html`。
- 必须保留 `_shared` 和 `assets` 目录。
- 不要只上传单个 HTML 文件，手势识别模型位于 `_shared/js`。
- 完整部署包约二十多 MB，首次打开需要等待手势模型加载。

## 隐私说明

摄像头画面只在浏览器本地用于手势识别，本项目没有上传视频画面的代码。
